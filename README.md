Simple E-Commerce Store

SHORT PROJECT DESCRIPTION
This project is a simple and fully functional e-commerce web application where users can browse products, view product details, add items to a shopping cart, and place orders after logging in. An admin panel is included to manage products and orders. This project demonstrates full stack web development using Django with database integration.

Overview
This is a simple online shopping website built using Django. Users can register, login, browse products, add items to the cart, and place orders. The admin can manage products and orders through the admin panel.

Features
User registration and login
Product listing and product details
Shopping cart system
Order placement and management
Admin panel for product and order control
Database integration using SQLite

Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: Django (Python)
Database: SQLite

Project Status
Completed Successfully

Use Case
This project is suitable for internship submission, college mini project, and beginner-level full stack practice.
